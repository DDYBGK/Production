#AutoSeg3D：点云深度学习语义分割可视化工具
我将自主创新的 LCHNet 算法 —— 一款基于点方法的点云场景语义分割深度学习算法，部署于 Qt 界面中，开发出了这款可视化的自动化点云语义分割工具。​
工具的界面基于 PyQt 搭建，设计有左右双显示区域及多组功能按钮，通过信号与槽函数实现顺畅交互：左侧区域专门用于展示原始点云场景，右侧则同步呈现语义分割后的结果；点云的渲染环节采用 OpenGL 实现，能清晰、流畅地呈现点云细节。​
其核心功能涵盖点云文件加载、点云场景自动化语义分割，以及深度学习模型切换 —— 目前已集成 2 种模型，后续可通过添加权重文件与对应模型类灵活扩展。​
该工具应用场景广泛，可服务于具身智能机器人、场景解析等实际领域；同时，它能直观对比不同模型的性能优劣，为相关学术研究提供有力支持，兼具实用价值与研究意义。
